# Python 练习

记录我的 Python 学习过程和练习代码。

## 学习进度

- **第一章**：变量与数据类型 —— `type()`、`isinstance()`、字符串拼接、转义字符与格式化输出
- **流程控制**：`if` / `elif` 判断、`match` 匹配、`for`、`while`、嵌套循环
- **数据容器**：字符串、列表、元组、集合、字典

## 目录结构

```
第一章/      基础语法与入门练习
流程控制/    条件判断与循环
数据容器/    字符串 / 列表 / 元组 / 集合 / 字典
函数基础/    函数的定义与调用
```

## 文件命名规则

格式是 `主题_序号_说明.py`。

**每个文件都是一个可以直接运行的独立练习**：同一个知识点的不同写法、旧的试错版本，各自放在独立文件里（序号相邻），不用再来回加 / 删 `#` 注释。

## 各文件夹里有什么

### 第一章（基础语法）

| 文件 | 练习 |
| --- | --- |
| `002_01_演示_变量类型与引号.py` | 变量类型判断、引号与转义字符、字符串拼接 |
| `002_02` ~ `002_09` | f 字符串、`+` 拼接的规则、时间转换、温度转换、打折计算、判定偶数、运算符、找零计算 |
| `projects01_01_print与变量.py` | print 输出与变量 |
| `projects01_02_变量交换.py` | 变量交换 |

### 流程控制

- `if语句_01` ~ `10`：三角形类型判断、奇偶数、闰年、分数等级、BMI（两种写法）、`match` 三种用法、密码验证
- `for循环_01` ~ `06`：输出偶数、倒序输出、1~100 求和、阶乘、统计字符出现次数、for-else 判断质数
- `while循环_01` ~ `02`：1~100 求和、`while True` 计算器
- `嵌套循环_01` ~ `08`：打印矩形、倒三角、数字三角、金字塔、空心图形、倒序数字三角、质数筛选、两数和为 10
- `循环综合_01` ~ `12`：3 的倍数计数、成绩统计、数字反转（两种写法）、回文数、水仙花数、斐波那契（含没写完的初版）、分数数列求和、字符分类统计（初版 + 改错版）、猜数字、1~100 奇数和

### 数据容器

- `string_01` ~ `11`：大小写与 `is` 判断、查找统计、去除空白、分割拼接、`replace` 替换、回文判断（三种写法）、单词数统计（两种写法）、字符串比较
- `list_01` ~ `10`：增删改查、遍历、查找统计、排序反转、去重、最值与平均、筛选偶数、嵌套列表成绩统计、`copy` 浅复制、删除元素的两种写法
- `tuple_01` ~ `10`：基本操作、修改元组（两种方法）、添加元素、拼接重复排序、拆包与交换变量、一周气温统计、元组记录数据、单元素元组、元组拼接的坑
- `set集合_01` ~ `12`：创建与类型、列表去重、添加删除、集合运算、子集判断、班级名单运算、去重保序、统计不同字符、两个列表的运算、空集合与字典的区别、集合不能装列表
- `dict字典练习1.py` / `dict字典练习2.py`：统计单词出现次数、嵌套字典的成绩统计

### 函数基础

- `函数基础练习一.py`：摄氏 ↔ 华氏温度转换函数 + 用 f-string 格式化打印对照表

## 怎么运行

- **PyCharm**：打开文件 → 右键 Run，或按 `Shift + F10`
- **命令行**：`python 文件名.py`（项目用的是 `.venv` 虚拟环境）
