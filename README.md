# Python 练习

记录我的 Python 学习过程和练习代码。

## 学习进度

- **第一章**：变量与数据类型 —— `type()`、`isinstance()`、print 输出
- **流程控制**：`if` / `elif` 条件判断、`for` 循环、`while` 循环、嵌套循环
- **数据容器**：字符串、列表、元组、集合、字典

## 怎么运行

- **PyCharm**：打开文件，右键 → Run，或按 `Shift + F10`
- **命令行**：`python 文件名.py`（本项目用的是 `.venv` 虚拟环境）

## 关于文件里注释掉的代码

同一个知识点常常写了好几个版本，旧版本用 `#` 注释掉保留下来当笔记，只有当前版本是"活着"的。

想跑某个旧版本，把对应几行的 `#` 去掉、再把现在跑的那个注释上就行。Python 里每个文件都能独立运行，所以不像 C++ 那样需要配工程 —— 但同一个文件里同一时间也只能有一个版本在跑。
